# 界面文案规则

写或改界面时遵守：

1. 不要给标题配一句复述它的副标题。
2. 不要在每个模块下面加说明文字。
3. 免责声明和更新时间只在页脚出现一次。
4. 按钮文字写清动作，不要再加「点击按钮即可…」。
5. 空状态只写一句话，再给一个操作按钮。
6. 必要的解释放进 ⓘ 提示气泡，默认不显示。
7. 危险或不可逆的操作（删除、覆盖已保存内容、会花钱的 AI 生成）必须保留清楚的后果提示。
8. 去掉说明后，第一次用的人仍要能看懂下一步点哪里、点了会发生什么。
9. 改写已有界面时，先删多余的标签和说明；清晰度下降时调整布局和按钮文案，不要把说明加回来。
10. 只有图标的按钮必须有中英双语的 `aria-label`；表单保留标签。
