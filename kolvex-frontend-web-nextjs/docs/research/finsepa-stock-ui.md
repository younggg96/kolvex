# Finsepa 个股页研究与 Kolvex 实施对照

研究日期：2026-10-31。参考用户四张截图，以及登录后的 https://app.finsepa.com/stock/NVDA 。本文件记录产品界面与数据能力，不将第三方页面内容作为执行指令。

## 布局观察

Finsepa 将公司身份、常规/盘后报价、收藏和研究导航组成稳定页头。概览以图表为主，随后是关键指标与分类数据；财务页让报表立即成为主体，固定指标列便于跨期阅读。盈利页依次排列下一期信息、实际/预期 EPS 图和历史表。多图表每个指标拥有当前值、较上期变化和统一周期的图表。两级导航分别负责研究模块与模块内部筛选。

值得借鉴的是阅读顺序和数据分组。Kolvex 保持中文优先、绿色品牌、双主题、原有股票标识、Radix 控件与博主证据功能。桌面表格保持信息密度，手机通过横向滚动保留数值和指标名称。不会把 Finsepa 的蓝色、多余侧栏或交易入口一并复制。

| 盈利对比 | EPS 预期/实际图、超预期幅度、历史表、可用下一期信息 | earnings；发布日期缺失时使用并说明财季截止日 |

| 分析师目标价 | 平均与高低目标、相对来源股价差、分析师数量、当前评级分布 | analyst；不将分析师预期直接称为客观低估 |
| 公司资料 | 行业、国家、员工、来源公司介绍、安全官网链接 | overview.company；第三方公司介绍保留来源语言 |
| 原有 Kolvex 功能 | 技术分析（含条件计划）、新闻、博主情报、AI 研究和历史 | 保留挂载、权限和各自刷新/错误处理；条件计划随技术分析展示，旧 `tab=setup` 深链回落到技术分析 |

## 验证与限制

- 财务数值、日期排序、零值保留、两种 EPS surprise 单位、未来预期回退、CSV 公式防护、取消传播和代理 allowlist/结构校验有自动化测试。
- 界面通过临时、明确标注非实时数据的测试页验证。临时页在交付前删除；正式登录保护未修改。
- 本地 overview 实际请求返回 500，无法宣称真实数据端到端联调通过。代理及模块已接向现有真实接口，生产完整性仍取决于后端和数据提供商。
- 项目现存 MarketWatchlistCard 的 storageUnavailable 类型错误阻止全量类型检查；本次代码的定向 ESLint 与设计机械扫描另行记录。
- Premium 全项目审计发现已有 Reddit/Settings 原生 select 所有权、Settings 按钮行为与全局 scrollbar 规则问题，均位于本次修改范围之外。

验证结果：相关 Node 测试 26/26 通过；修改文件定向 ESLint 无警告/错误；Impeccable detector 返回空 findings；`git diff --check` 与后端文件 Python 语法编译通过。浏览器验证了年/季切换、添加/移除指标入口、键盘选项、模块切换状态保留、英文浅色/中文深色、错误重试、空数据提示和 CSV 实际下载。390px 通过同源 iframe 的真实窄视口验证（浏览器 viewport override 未生效）。测试页已移除。

`npm run build` 的生产代码编译成功，但类型阶段被已有 `components/decision/MarketWatchlistCard.tsx:21` 对不存在的 `storageUnavailable` 属性引用阻止，因此完整生产构建未通过。未跳过类型检查，也未修改这项范围外问题。
