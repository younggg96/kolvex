# Web → React Native migration ledger

Reference clients: `../kolvex-frontend-web-nextjs` and `../kolvex-backend-py`. The migration is a sibling Expo application, not an embedded website or a brownfield replacement. Web routes, API contracts and `lib/productFeatures.ts` define the reference. The active Web source is being edited concurrently; this records the audited routes and explicit differences, rather than claiming perpetual parity with a moving branch.

## Not a full acceptance / release claim

Native freehand drawing gesture parity, dormant Plaid/portfolio flows, native binary signing/distribution and device accessibility acceptance remain. No working Xcode/simctl or native device is available on this host. Public preview and negative auth checks do not establish successful private mutations, real AI execution, SwiftUI layout/keyboard/touch correctness or native material rendering. A test account and a native build/device are needed for those checks.

No RLS, administrator grants or OAuth provider settings were relaxed or changed as part of the port. Test execution never created/deleted a real account, submitted an AI job, uploaded a real avatar, changed a role or connected a brokerage.
