# Web → React Native migration ledger

Reference: `../kolvex-frontend-web-nextjs` (routes, `lib/productFeatures.ts`) and `../kolvex-backend-py`. First audited against commit `839a958`; the rows marked 2026-11-09 below were added against `170a02a`. The Web keeps moving, so this records what was checked, not perpetual parity.

## Login required

The app has no guest mode, by the owner's decision. Every route except `sign-in` and the auth callbacks requires a session. This goes beyond the Web, whose public reading pages (`/stocks`, `/creators`, `/research`, shared creators) have no native equivalent when signed out; shared links lead to sign-in. Rows below that say guest or public access describe code now removed, and anything marked `W` was seen before this change.

## How to read the status columns

| Level        | Meaning                                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| **Code**     | Implemented; TypeScript, lint and unit/contract tests pass.                                               |
| **Bundle**   | Included in the Metro/Hermes iOS and Android exports. Not a native compile.                               |
| **RN-Web**   | Exercised with real backend data in the React Native Web preview at 390 px. Does not stand in for native. |
| **Native**   | Ran on an iOS/Android simulator or device.                                                                |
| **Business** | The real signed-in or mutating flow completed end to end.                                                 |

**No mutating flow has reached Business, and Native is only partial; signed-in reads are in `VERIFICATION.md`.** The iOS simulator now runs the five tabs, stock detail, Ownership, Peers, the technical chart gestures, report actions, creator sharing and `kolvex://` links; `VERIFICATION.md` lists exactly what was and was not exercised there. Android is set aside and no test account was supplied. The table's status column still records pre-simulator levels. See `VERIFICATION.md`.

Status abbreviations: `C` Code, `B` Bundle, `W` RN-Web. `Auth` means the screen requires sign-in and its success path was not exercised. `W` on a row means the screen's main read path was seen in the preview, in this pass or an earlier one recorded in `VERIFICATION.md`. The translate toggles and automatic headline translation added to the X and News rows are only `C B`.

## Native material and layout

| Requirement                    | State                                                                                                                                                                            |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Real SwiftUI glass             | `Glass material` uses `@expo/ui` `glassEffect` on iOS 26+. Older iOS falls back to blur; Reduce Transparency, Android and Web use an opaque surface.                             |
| Glass only on chrome           | **Changed in this pass.** `Glass` is now opaque by default. Data and reading cards no longer sit on glass; search bars, the stock action bar and the chat attachment bar use it. |
| Native tabs                    | `NativeTabs` from Expo Router.                                                                                                                                                   |
| Layout conversion              | Wide tables became cards or a fixed-label scroller; the More screen became grouped rows.                                                                                         |
| Rendering, keyboard, type size | **Partial.** Rendering seen on the iOS simulator for a few screens; keyboard and type size unverified.                                                                           |
