# 虚拟交易系统

## 产品闭环

AI 技术分析 / 图表划线 → 检查订单草稿 → 模拟撮合 → 持仓和净值 → 交易复盘 → 自愿公开交流。
虚拟账户独立于真实券商账户，不调用券商交易接口。

## 第一阶段：可用的模拟交易工作台

- 每位已登录用户一个 USD 100,000 账户，整股，无杠杆；支持美元股票和 ETF。
- 开多、开空、指定持仓部分/全部平仓。每笔开仓独立成 lot，便于关联策略与止损。
- 市价、限价、突破 stop 入场订单；GTC 挂单和撤单。每个 lot 可附带止损、止盈，触发后关闭其剩余仓位并取消相关平仓挂单。
- 固定模拟费用：单次成交金额 1 bp；市价、突破单、止损和平仓额外使用不利方向 5 bp 滑点。限价不穿越限价。
- 多单买入扣现金；空单冻结等额成本作为抵押，卖空所得不增加可用资金。净值 = 现金 + 多单市值 + 空单抵押及浮盈亏。
- 挂单冻结预计本金和费用，平仓挂单冻结数量，禁止重复使用资金或超卖。空单抵押耗尽按观察价强平；跳空可导致负净值。
- 展示净值、现金、可用资金、冻结资金、已实现/未实现盈亏、成交次数、平仓胜率、净值采样曲线、完整成交记录。
- AI setup 一键带入股票、方向、入场价、止损、首个目标及理由。只生成草稿，用户确认数量和订单类型后提交。
- 用户可为已关闭持仓填写复盘并公开；公开快照由服务器账本生成，包含费用、方向、成交和净盈亏，不暴露私人账户资产。交流沿用研究页面入口。

## 撮合边界

Yahoo 报价可能延迟。仅 USD 且明确为股票/ETF 的报价可交易；不使用浏览器提供的成交价。
市价撮合需要纽约常规时段和 20 分钟内的供应商时间戳；过期/未知时间报价只用于带明确时间的估值，不能撮合。
后台每 60 秒扫描有未完成订单/持仓的账户，按实际观察到的新报价撮合；用户手动刷新也会同步。
不重放后台宕机期间价格路径，不用日 K 的 high/low 推测成交次序；只在下次有效报价触发。
止损止盈不是价格保证。无借券费、股息、拆股调整或真实流动性模型，发生公司行动时应暂停相关策略。

## 存储与一致性

Supabase 保存服务端账本，数字使用 Decimal 并序列化为十进制字符串。账户行的 version 比较更新保证整个订单/成交/资金变更原子性；冲突后重新读取并重新计算。
每个命令使用 UUID 幂等键。客户端只能读自己的账本；写操作只能由带用户身份校验的后端完成。
公开复盘单独存储，默认私人，无账户资产和用户邮箱。仅作者可撤回。
MVP 每账户最多 5,000 笔订单、200 个同时持仓、100 个未成交订单；图表保留最近 1,000 个净值采样。后续迁移至规范化事件账本和归档查询。

## 后续阶段

1. 更高质量的分钟行情、交易所日历、拆股分红、借券费用、强平与回测一致模型。
2. 订单修改、trailing stop、OCO/分批止盈、批量风险预算、策略版本与 R 倍数、最大回撤、基准对比。
3. 复盘评论、关注、举报、审核和策略排行榜。排名至少要求账户龄与样本量，公开回撤和模拟规则，避免仅按收益诱导过度风险。
4. 历史回放练习、教学课程、AI 复盘建议。历史回放与当前行情账户严格隔离。

## 验收

测试多空与部分平仓的现金/净值守恒、费用、滑点、止损止盈互斥、限价和突破触发、撤单解冻、幂等与并发版本冲突、过期行情、身份隔离、公开快照来源；前端类型检查、构建和桌面/窄屏交互检查。
