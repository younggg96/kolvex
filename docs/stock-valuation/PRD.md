# Kolvex 股票估值分析 PRD

本文件根据本次聊天中已确认的方案恢复。网页端优先，兼顾手机端；当前开发进度和真实数据核验见 [开发记录](./README.md)。本文定义目标产品，不表示功能已经实现。

## 产品目标

用户在个股页查看当前估值位置、历史变化和未来不同情景的目标价格，并能够理解、修改和保存计算假设。优先复用现有行情和 SEC 财务数据，不购买新的数据 API；服务器、存储、开发成本另计，公开行情展示权限需另行核实。

首批覆盖通过数据核验的 USD 报价、USD 财报、US GAAP 普通股。指数、ETF、银行、保险、REIT、ADR 和非 USD 财报股票暂不进入首批自动估值覆盖。没有足够数据时明确显示不可用原因。

## 入口和页面顺序

在现有个股工作台增加“估值”Tab，概览提供一条摘要链接，支持 `tab=valuation` 定位。沿用现有页面、语言和主题。

1. 股票身份、当前价格和行情时间。
2. 当前估值：保守、基准、乐观参考值，当前价格在刻度上的位置，以及计算依据。
3. 历史走势：价格与参考估值、PE 倍数、折价/溢价三个视图。
4. 未来情景：未来三个公司财季的目标日期、三情景价格和相对现价的空间。
5. 假设与经营条件：EPS、目标 PE、增长率等参数及来源。
6. 数据与方法：期间、申报日、模型版本、覆盖范围、原始财报链接。

网页图表可与选中日期详情并排。手机端堆叠，长按固定日期，未来情景按季度卡片呈现。两端使用同一后端、数据版本、口径和舍入规则。

## 当前、历史、未来的边界

| 模式 | 定义 |
| --- | --- |
| 当前估值 | 最新有效财报和明确模型假设下的参考值，与带时间的现价比较 |
| 历史估值重建 | 各时点已向 SEC 申报的信息，按固定版本规则重建；不声称是当年发布过的预测 |
| 未来情景 | 从今天出发，对指定未来日期的条件推演；不代表确定回报或分析师共识 |
| 个人模拟 | 用户修改参数后形成的结果，与系统参考曲线分开 |
| 真实预测档案 | 功能上线后实际保存的预测版本，可按同一目标日期比较修正历史 |

历史重建不声称覆盖早于 SEC 申报的所有新闻稿、电话会等公开信息；将来补充更早的正式来源，应另存数据版本。

## 历史图交互

默认三年，可选1年、3年、5年、全部；十年在覆盖足够后加入。范围不足时展示实际长度，缺失区间断线。历史价格每日变化，财报驱动的参考值按有效事件阶梯更新。

默认图显示价格、基准线、保守至乐观区间。十字线或点击日期显示当日收盘价、三个参考值、EPS、倍数、财报期间和来源；财报事件可查看输入变化。选中历史日期只更新历史详情，页首“当前”仍为最新状态。

另两个视图分别展示每日 TTM PE 与当时可得样本的 P25/P50/P75，以及 `价格/基准参考值−1` 的折价/溢价。三情景区间不是统计置信区间；只有统计分位使用分位术语。

历史分位采用此前有效样本中 `(小于当前值的数量 + 0.5×等于当前值的数量)/样本总数`；显示回看窗口、样本量和起止日期。当前和未来数据不得提前进入参考样本。

## 计算口径

设比较价格为 P，当前基准值为 V，未来目标价为 T：

```text
相对基准的价格空间 = V/P − 1
相对基准的折价/溢价 = P/V − 1
到目标日期的价格空间 = T/P − 1
```

例如P=100、V=125，空间为+25%，折价为−20%。未来空间不含分红、费用，不称作预期收益率。输入或分母无效时不输出百分比。

### PE 第一版

```text
PE = 同股本基准的价格 / 有效TTM稀释EPS
参考值_s = 有效TTM稀释EPS × 目标PE_s
```

默认目标倍数为公司自身过去五年、截止快照前一交易日有效日 PE 的 P25/P50/P75，对应保守/基准/乐观。至少252个有效交易日及四个独立财务输入版本；不足时不自动推荐区间，可明确输入个人倍数。参考倍数在财务输入事件更新时重算，期间冻结。显示三年曲线而每个点回看五年，最多需要八年基础数据。

该模型称为“历史 PE 参考估值”，不把历史市场定价宣称为客观内在价值。不能用同一天的价格除 EPS 得到 PE，再反算为合理价值。

优先使用已核验的 TTM EPS；可以采用全年/十二个月直接披露值，或四个连续同口径单季披露值求和并记录舍入差异。第四季度缺失时不能直接用全年减前三季累计 EPS，后续桥接估计须有独立推导标记、方法与误差核验，不静默混入默认曲线。

新季度已经披露但无法组成 TTM 时应报告缺口，不能把旧年度 EPS 当成最新 TTM。Yahoo 当前 EPS 可单独显示供应商口径，不与 SEC 历史无提示拼接。EPS≤0时 PE 不适用，不显示零目标价；极高倍数先检查单位和分母，不静默截断。

### 未来季度情景

用公司财季及目标期末日，区分财政年和自然年；未知日期标为预计，不将期末日当财报发布日期。第一版用与历史 PE 一致的 TTM 口径做机械推演：

```text
目标日期TTM EPS_s = 当前TTM EPS × (1+EPS年增长率_s)^h
目标日期价格_s = 目标日期TTM EPS_s × 目标TTM PE_s
h = 实际天数/365.25
```

无可核验公司预设时，增长率默认0%，标为“盈利不变的机械假设”。历史 CAGR 不自动作为未来预测，单季 EPS 不直接乘年度 PE。未来如增加 NTM，需配套 NTM EPS 和 NTM PE，独立切换。

同一日期保守≤基准≤乐观；情景交叉时提示用户修正，不静默交换名称。三情景由各自输入计算，不由基准固定加减百分比生成。经营条件若只是文字说明应明确标识；只有接入量化经营模型才参与 EPS 计算，事实附来源和日期。

### PEG 第二阶段

```text
目标TTM PE = 目标PEG × 未来3至5年EPS年增长率的百分数数值
参考值 = TTM EPS × 目标TTM PE
```

20%增长在公式中用20。增长≤0、基期亏损或预测不完整时不适用；不规定PEG=1必然合理。没有历史预测档案时，历史PEG仅作为有标记的规则重建或个人模拟。

### DCF 第二阶段

默认规划五年显式期的 FCFF 模型：

```text
FCFF = EBIT×(1−有效税率)+折旧摊销−资本支出−营运资本增加
企业价值 = 显式期FCFF现值和 + 终值现值
终值 = 第5年FCFF×(1+永续增长率)/(WACC−永续增长率)
股权价值 = 企业价值+可计入的非经营现金/资产−债务−其他优先索取权
每股价值 = 股权价值/对应稀释股数
```

经营现金流减资本支出不能直接当成已核验FCFF，再套 WACC 并重复扣债。若采用 FCFE，使用股权成本和独立模型版本。校验税率、折旧、再投资、债务、少数股东权益和股数的期间及单位，要求WACC>永续增长率、股数为正、输入有限完整。股权价值≤0时解释原因，不生成负股价。提供终值占比及敏感性矩阵。

## 数据、保存与版本

每个财务事实保留证券、公司、tag、单位、期间、财年/财季、数值、申报编号、申报日、可获得时间、来源链接、抓取时间和推导引用。所有申报版本共存；先按历史可用时间筛选，再选期间对应值。

精确披露时间不可得时，从申报日后下一实际交易日生效，并标记日期级精度。推导值取所有输入最晚的有效时间。后续重表达不能写回此前默认历史；最新重述重算属于独立视图和版本。

历史价格与EPS统一到有证据的同一股本基准。拆股不应改变PE和折价率，分红不调整PE用价格。币种、ADR比例或股票类别无法对齐时停止自动估值。处理53周年度、财年变化、来源冲突与缺失期间。

历史使用常规交易时段收盘价；当前使用可靠常规时段报价，盘后价单独展示。行情时间未知或币种不一致时不输出当前空间；过期行情和财务输入显示日期及原因。

用户可修改参数即时试算，普通试算不改系统历史。历史重算须主动开启“用我的假设重算历史”。登录后保存私人命名方案，快照、参数和版本一起保存；新财报不覆盖旧方案，重新计算另存版本。游客可本地试算。没有有效参数时保留上次有效结果并标明修改未应用。

AI仅作为后续解释层，不能生成无来源事实或修改数值，计算不依赖AI返回成功。不同模型独立展示，不平均成一个综合目标价。

## 状态和技术边界

支持首次回填、部分覆盖、不适用、输入缺失、来源不可用、过期、参数无效、无保存方案等状态。保留带时间的最后成功结果，不补零、不补造连续曲线。价格超出参考区间时刻度仍包含真实价格。

后端复用FastAPI与SEC接入，新增独立估值服务和接口，网页手机共用。财务版本、价格与公司行动、系统估值事件、私人方案版本、回填任务分别保存。系统结果仅后端写；私人方案按所有者授权，公开schema启用RLS。计算与缓存键包含证券、模型、数据版本、价格口径、范围和假设哈希。

接口规划：`GET /api/v1/valuation/{symbol}/summary`、`GET .../history`、`POST .../simulate`、`POST/GET .../scenarios`、`GET .../scenarios/{id}`、`GET /api/v1/valuation/jobs/{id}`。长回填返回202和任务标识，同一任务去重；试算不重新读取外部来源，保存前后端按同一快照校验。

结果必须包含币种、行情时间、财报期间、数据有效时间、输入引用、模型/规则版本、假设来源、结果模式、目标日期、覆盖和质量状态。不同EPS口径不能伪装为同一条线。

## 分期和验收

阶段A核验NVDA、AAPL、MSFT等候选数据，输出有效历史、EPS事件、缺口与拆股基准；未通过的不承诺连续历史。阶段B交付PE当前区间、历史三图、未来三财季推演、参数调整和方案保存，网页先行。阶段C增加PEG、DCF、敏感性分析、经营预测和手机完整功能。行业适配、提醒、分享和更长历史后续独立规划。

核心验收：无未来数据泄露；重表达不提前生效；拆股不改变倍数；缺Q4、断季和亏损的状态正确；价格空间/折价公式一致；参数变动不污染系统历史；旧方案可复现；网页手机数值一致；来源失败和回填可恢复；每个未来价格展示期限和假设。

有缓存摘要p95≤1秒、五年曲线p95≤2秒、本地参数预览≤150毫秒作为待实测预算。首次回填异步处理。上线排期由实际覆盖与开发资源决定。

## 2026-11-04 开发增补：公司估值计算器

已实现独立于历史曲线的 DCF／PE／PEG 公司计算器，默认进入该视图。DCF 明确区分企业价值、股权价值和每股价值，并包含必要终值再投资、现金债务桥接、逐年现金流和敏感性表。所有前瞻参数均为可修改假设；不把当前市场PE、供应商当前财务或AI生成数据作为历史合理估值。财务数据优先四季度TTM，缺季回退财年并明确标示。详细口径、范围、接口与未完成项以同目录 README 的当前开发记录为准。

当前公司估值不局限于原三家试点；历史PE曲线仍仅覆盖已审核的NVDA、AAPL和MSFT。私人方案保存、自动经营预测及行业专用模型不包含在本次交付。
