# 观点事后表现与回测

三部分共用同一套计算方法（`app/services/opinion_backtest.py`）：

1. **界面上的「发布后股价」**（产品功能）：观点卡片下面一行，写视频发布后股价的实际变化。
2. **界面上的「回看」页**（产品功能）：全部看多 / 看空观点之后，股价相对 SPY 的整体表现。
3. **回测脚本**（内部研究）：更细的拆分和按博主的统计，只出报告，不进界面。

## 界面：发布后股价（第一期）

- 位置：Web `/dashboard/youtube-opinions` 里所有「只看一只股票」的观点卡片：
  - 股票页（`?tab=stocks&stock=AMD`）的「历史观点」；
  - 「某博主 × 某股票」页的「历史观点」和底部的「其他博主的看法」。
  
  同一页只请求一次接口（`hooks/useStockOutcomes.ts`，按股票共用缓存）→ `OpinionCard` → `OpinionOutcome.tsx`。归属 `youtubeOpinions` 功能开关，没有新导航入口。
- 内容：已满的持有期（5 / 20 个交易日）先列出；还有没满的，再加一项「至今 N 个交易日」，算到最近一个收盘日。例如 `发布后股价 ⓘ 5 个交易日 -5.9% 同期 SPY +1.7%`、`发布后股价 ⓘ 至今 3 个交易日 -5.8% 同期 SPY -0.3%`。「至今」正好等于某个已满持有期时不重复显示。
- **只陈述事实，不判对错**：不显示「说对 / 说错」、胜率、准确率、博主排名。接口也不返回按方向调整后的数值。
- 状态：发布后还没有完整交易日、拿不到行情（港股、日韩股等）、缺发布时间，各有一句说明；行情接口失败显示「暂时无法加载」。任何情况下都不用 0 代替。
- 接口：`GET /api/v1/youtube-opinions/stocks/{ticker}/outcomes`（`app/services/opinion_outcomes.py`）。独立于观点接口，行情慢或失败不影响观点本身的加载；行情失败返回 503。行情在后端内存缓存 30 分钟，失败不缓存。当天未收盘（美东 16:30 前）的 K 线不参与计算。接口里每条观点的 `latest` 是「至今」的数值（入场开盘价到最近收盘），`horizons` 是固定持有期。
- 测试：后端 `tests/test_opinion_outcomes.py`，Web `scripts/opinion-outcome.test.cjs`。
- 还没做：只看博主时的「最新观点」和视频卡片（一页混着多只股票，需要批量行情）；个股图表上的标注；博主层面的汇总（需要更长的数据，见下方「读结果时注意」）；App 端。

## 界面：回看页（整体表现，第一期）

- 位置：`/dashboard/youtube-opinions/review`，博主观点里「按股票 / 按博主 / 回看」切换的第三项；每张卡片「发布后股价」的 ⓘ 里也有入口。归属 `youtubeOpinions` 功能开关，不进左侧主导航。
- 内容（2026-11-15 第二次改版：用专业术语，解释性文字全部收进 ⓘ，页面上只留标签和数字）：
  - 持有期切换「5 日 / 20 日」（交易日），起算方式写在旁边的 ⓘ 里；
  - 看多、看空各一张卡片：「平均超额收益」+ 大号数字（超额收益 = 个股持有期收益 − 同期 SPY 收益，公式、中位数、95% 置信区间在 ⓘ 里）；两条以 0 为中线的横条：个股平均收益、SPY 同期收益；「跑赢 SPY 占比 47%（260/557）」（条数用接口的 `beat_count`）；
  - 「超额收益分布」直方图：每 5% 一档，柱上写条数，0% 处一条虚线，两端写「← 跑输基准 / 跑赢基准 →」，0% 左边的柱子用跌色、右边用涨色；悬停显示档位和条数；分档和点击说明在 ⓘ 里，不再有图下提示栏；
  - 点开一档：标题用标签表示（看多 · 5 日 · 超额 0% ~ +5% · 190 条）；每条观点带公司 logo、博主头像和名字（点名字进「单个博主」）、发布日、原视频图标；下面三格：个股收益、SPY 同期、超额收益；
  - 同期 SPY 走势：标题旁 ⓘ 说明怎么读；图上方是区间涨跌和图例（SPY 收盘价 / 看多观点每周 / 看空观点每周）；
  - 按置信度、观点强度拆分；
  - 页脚一行：「有效样本 N 条 · 看多 · 看空」（完整的去重、不计入、无行情说明在 ⓘ 里）· 数据截至日期 · 免责声明。
- **观点标的就是 SPY 本身**：超额收益恒为 0，没有意义。这类观点不计入任何统计（平均、占比、直方图、拆分、博主个人卡片），在页脚 ⓘ 里单独写条数（`counts.on_benchmark`）；在逐条列表里照常列出，但不显示「SPY 同期」和超额收益，改为「与观点方向：一致 / 相反 / 持平」加 SPY 本身的收益，旁边 ⓘ 解释原因。「一致 / 相反」只说价格走向和观点方向的关系，不是「说对 / 说错」的评价。
- **只陈述事实**：看多、看空分开统计，都是「股价减 SPY」，不按方向翻转成「说对 / 说错」。不出现准确率、胜率、博主名字或排名；接口里也没有任何博主字段（测试保证）。
- **样本门槛**：一组少于 30 条只显示条数，写「样本不足」，不给平均数或比例。
- 不按博主自己说的持有期拆分：这个字段是自由文本（「短期」「1-3 months」「短线」混用），先要统一。
- 接口：`GET /api/v1/youtube-opinions/review`（`app/services/opinion_review.py`）。全部观点和几百只股票的行情一次批量下载，约 5 秒算完。结果是一份快照，存在内存和 `data/review/snapshot.json`；每过一个美东 16:30 收盘点后，第一个请求在后台重算，期间先返回旧快照并带 `refreshing: true`。完全没有快照时返回 503（`detail: "building"`），页面显示「正在汇总」并每 5 秒重试。构建失败后 10 分钟内不重试。
- 测试：后端 `tests/test_opinion_review.py`，Web `scripts/opinion-review.test.cjs`（含中英文文案一致、文案不出现「准确率 / 胜率」）。
- **点进观点**（第二期）：分布图的每根柱子都可以点，在两张卡片下方通栏展开这个区间里的观点（从新到旧，一次 10 条，最多列 200 条），展开时自动滚动到列表。标题是一句话，例如「博主看多后 1 个月，股价跑输大盘 15%–20% · 37 条」；每条写股票、博主、「某日说看多」，下面三格并排：股价涨跌、同期大盘涨跌、差距（「跑输 17.5%」），并能跳回原视频、该股票的行情页、该博主。接口 `GET /api/v1/youtube-opinions/review/opinions?horizon=&sentiment=&low=&high=`（含 low、不含 high，和直方图一致）。

## 界面：回看页「单个博主」（第三期）

- 位置：回看页标题下「全部观点 / 单个博主」切换的第二项（不叫「按博主」，避免和顶部切换重名）。地址 `?view=creators&creator=<channel_id>`，可以直接分享；全部观点列表里点博主名字也会跳到这里。
- 内容：
  - 先选博主（下拉框，按观点条数从多到少、再按名字排列，只是活跃度，不是表现）；
  - 选中后列出这位博主说过的股票（每只后面是观点条数），可以按股票筛选；
  - 逐条列出观点（从新到旧，一次 20 条）：公司 logo、股票（点开是行情页）、看多 / 看空、发布日、原视频图标；下面两格「5 日」「20 日」，各写超额收益（带正负号）和「个股 · SPY」各自的收益；还没满期的写「未满 20 日」，不用 0 代替；观点标的是 SPY 本身时改写「一致 / 相反」（见上）；
  - 博主名字前有头像，下拉框里每位博主也带头像；
  - 右侧复用博主个人卡片（门槛同第二期，不到门槛只写条数），这里不显示「看全部观点」按钮。
- **只陈述每条观点的事实**：接口不返回这位博主的平均数、跑赢比例或任何排名（测试保证），汇总数字仍只在达到门槛的个人卡片里出现。
- 范围：和全部观点用同一份快照、同一套去重规则（7 天内同股同方向只列第一条）；中性观点、视频发出后还没开过盘的观点、拿不到行情的股票不列出。规则写在 ⓘ 里。
- 接口：`GET /api/v1/youtube-opinions/review/creators`（选择列表）、`GET /api/v1/youtube-opinions/review/creators/{channel_id}`（这位博主的观点），都从快照读取，不额外下载行情。
- 测试：`tests/test_opinion_review.py`（`CreatorOpinionTests`、路由），`scripts/opinion-review.test.cjs`（地址读写）。

## 界面：博主主页的个人卡片（第二期）

- 位置：只看某位博主时（`?tab=creators&creator=…`）的侧栏顶部「观点发布后的股价」。只出现在这位博主自己的页面，任何地方都不做博主之间的比较或排序。
- **门槛**：这位博主满 20 个交易日、有方向的观点至少 30 条，且这些观点跨 90 天以上，才显示数字。不到门槛时只写一句「满 20 个交易日的观点目前 N 条、跨 M 天；满 30 条且跨 90 天后显示」，再给「看全部观点之后的整体表现」按钮。2026-11-15 的真实数据里没有一位博主达到门槛（最多 53 条，但只跨约 12 天）。
- 内容：5 / 20 个交易日切换；看多、看空各一块：条数、股价相对 SPY 的平均、跑赢 SPY 的比例；再列**前一半时间 / 后一半时间**各自的平均（每半至少 10 条才给数字）。分界日是这个持有期计入的观点的入场日中位数，每个持有期各算一次。
- 接口：`GET /api/v1/youtube-opinions/creators/{channel_id}/review`，和「回看」共用同一份快照；`/review` 返回前会去掉按博主的数据和观点列表。
- 测试：`tests/test_opinion_review.py`（门槛、跨度、前后两半、未知博主、区间列表、旧快照文件重算、接口），`scripts/opinion-review.test.cjs`（`binQuery`）。

## AI 聊天：博主观点后股价（`get_creator_record`）

- 位置：AI 聊天和研究工作区的「博主」技能。用户问「某博主说的票后来怎么样」「能不能信某博主」时，Agent 调这个工具。没有新界面。
- 计算：`app/services/creator_record.py`，方法同上；看多、看空分开，都是「股价减 SPY」，5 / 20 个交易日，另给每条最新观点的「至今」表现和视频链接。
- **只陈述事实**：和回看页同一条规则。工具不返回按方向翻转的数值，工具说明和系统提示词都要求模型不说「说对 / 说错」、不给准确率、胜率、排名、不比较博主（测试保证返回里没有这些字段）。
- 样本门槛（按上面第二期的个人卡片标准）：一组至少 30 条、入场日期跨 90 天以上才给平均数和跑赢 SPY 的比例，同时给前后两半时间各自的平均；不够时只给条数，提示词要求模型不要自己算平均。
- 行情：复用发布后股价的缓存（30 分钟，失败不缓存）。单只股票拉不到计入 `price_unavailable`，全部失败返回错误。
- 测试：`tests/test_creator_record.py`。

## 回测脚本

不是产品功能。用来回答：博主说看多 / 看空之后，这只股票有没有跑赢 SPY。

### 运行

```bash
cd kolvex-backend-py && python scripts/backtest_kol_opinions.py --since 2026-01-01
```

- 只读：用 anon key 读 `youtube_stock_opinions`（公开 SELECT 策略），不写数据库，不调用模型。
- 行情：yfinance 复权日线，按天缓存在 `data/backtests/prices/`。
- 输出到 `data/backtests/`（已加入 `.gitignore`）：`report.md`、`events.csv`（每条观点一行）、`channels.csv`。
- 参数：`--horizons 1,5,20,60`、`--detail-horizon 20`、`--dedupe-days 7`、`--min-n 10`。

## 方法（METHOD_VERSION 1，界面和脚本共用）

代码：`app/services/opinion_backtest.py`，测试：`tests/test_opinion_backtest.py`。

- **事件时间**用 `video_published_at`（换算成美东时间）。不用 `opinion_date`，它默认是上传当天，可能晚于视频。没有发布时间的观点跳过。
- **入场**：美东 09:30 前发布，按当天开盘价；否则按下一个交易日开盘价。
- **出场**：持有第 N 个交易日的收盘价（N=1 即入场当天开盘到收盘）。
- **超额收益** = 个股收益 − 同期 SPY 收益。SPY 缺数据时超额收益为空，不退回用原始收益。
- **方向**：bullish 取正，bearish 取负，得到 `signed_excess`（> 0 表示说对了）。neutral / mixed 只计数。
- **去重**：同一博主对同一股票同一方向，7 天内只保留第一条。
- 当天还没收盘的 K 线不参与计算。价格还没覆盖到的持有期记为 pending，不当作 0。拉不到价格的股票记为 `no_price_data` 并在报告里列出。
- 统计：胜率（Wilson 95% 区间）、均值、中位数、t 值；按情绪、置信度、强度、博主自述期限、博主分组。博主表按中位入场日切成前后两段，方便看前段表现好的博主后段是否还好。

## 读回测结果时注意

- 不含手续费和滑点。
- 拉不到价格的股票（退市、非美股）被排除，结果会偏乐观。
- 同一时段的观点高度相关（大家同一周说同一批股票），t 值会偏高。
- 数据只覆盖很短的时间段时，结果反映的是那段行情，不是博主的长期水平。
- 从很多博主里挑表现最好的那个，会高估其能力。
