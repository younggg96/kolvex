# 内容翻译

X 帖子、新闻标题和研究报告的机器翻译共用 Next.js 的 `/api/translate`。它与界面文案的中英切换分开。译文用于阅读，原始内容不会被覆盖。App 的翻译也请求同一接口，Web 发布后即可使用新的服务端行为。

- 接口兼容 GET `?q=…&tl=zh-CN` 和 POST `{ q, tl }`。Web 按 URL 编码后的长度选择 GET 或 POST；服务端按编码长度分段，保留 Unicode 字符和段间空白。
- 每次上游请求最多等待 5 秒。主入口失败时切换到第二个 Google 入口；两者均失败时，短暂等待后尝试一次主入口。主入口返回 429 时不再重试它。
- 同一进程内合并相同原文和目标语言的并发请求。只缓存经校验的成功译文，最多 256 段，每段保留 1 小时；失败不缓存，也不记录原文。
- 上游均失败时返回 503，阅读界面可保留原文并重试。两个入口同属 Google，仍受其服务可用性和限流影响。

回归测试：`node --test scripts/news-feed.test.cjs` 覆盖上游无效响应、限流、恢复、并发请求合并和长文本分段。
